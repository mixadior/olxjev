# OlxJev Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve a free-text real-estate request («хочу зняти однушку квартиру в Харкові до 10к гривень в центрі») into OLX.ua `/olxwizard` bfc values and a search URL, with Jev making the wizard's choices in at most two API calls.

**Architecture:** A deterministic pre-pass extracts numbers and shortlists cities. Stage 1 (one `Evaluate`) picks the category leaf, city and region. The bfc order tree then yields the elements that apply, and stage 2 (one `Evaluate`) resolves them: `choice` for single-choice and numeric fields (numbers as options), one `noul` per option for multi-choice fields. Post-checks (threshold, from ≤ to, one number per field family) produce `Result.Values`, which feed the existing `search_olxua.OlxBuildUrl`.

**Tech Stack:** Go 1.27.0, `github.com/mixadior/bfc` v0.1.0, `github.com/mattn/go-jev` v0.0.3 (TypeSafe Jev API), `github.com/rs/zerolog`, `gopkg.in/yaml.v2`.

**Spec:** `docs/superpowers/specs/2026-10-14-olxjev-design.md`

## Global Constraints

- Module path `feodosian.com/olxsearch`; Go `1.27.0` (go.mod); go-jev pinned at `v0.0.3`.
- New Go files use **4-space indentation, no tabs** (CLAUDE.md). Do **not** run `gofmt -w`/`goimports` on new files. Existing files you edit (`cmd/bot/main.go`) keep their current tab indentation.
- Jev backend: hosted TypeSafe API only (`jev.DefaultURL`); the CLI `-endpoint` flag exists only so tests can point at an `httptest` fake.
- At most **two** Jev `Evaluate` calls per query; never ask about elements the order tree does not reach for the chosen category/city.
- Stage-2 Jev `state` carries human-readable labels only (`"Категорія"`, `"Місто"` or `"Область"`), never IDs.
- `filter_bool_*` values other than `"1"` are never stored (`OlxBuildUrl` treats any non-empty bool value as an active filter).
- Multi-choice values are joined with the element's `ValuesSeparator` (`;`), option keys sorted ascending.
- Default threshold `0.5`; default city shortlist `8`; Jev client `WithTimeout(30*time.Second)`, `WithMaxRetries(3)`.
- Always commit with an explicit pathspec (`git commit -m ... -- <paths>`): the main checkout has unrelated staged deletions (`adminui`, `bot`) that must not be committed. End every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

Inputs the spec implies but its happy-path tests don't cover, most likely to bite first. Each one has a test in the task that owns the code:

1. **A pasted ad full of numbers** («Продам 3к квартиру 2015 р. 75 м2 5/9 поверх ціна 85 000$ тел. 067 123 45 67»): the phone and year must be skipped, «3к квартиру» is 3 rooms (not 3000), and `5/9` gives 5 and 9. → Task 2 `TestExtractNumbersPastedAd`.
2. **Two cities in one query** («переїжджаю з Києва до Львова, шукаю квартиру у Львові»): both must reach the shortlist so Jev can choose. → Task 4 `TestShortlistTwoCities`.
3. **Latin/translit input** («kvartyra kharkiv 10k»): the shortlist is empty without panicking, and the region question is the fallback. → Task 4 `TestShortlistLatinIsEmpty`.
4. **A Jev answer with no confidence and no probabilities** (an API shape surprise): it must be rejected as below threshold, not accepted as a match. → Task 6 `TestResolveZeroConfidenceIsRejected`.
5. **Missing answers in a stage-2 response** (keys absent or nil): every element is skipped and nothing is stored or panics. → Task 6 `TestApplyStage2MissingAnswers`.

```go
import (
    _ "embed"
    "errors"
    "fmt"

    botform "github.com/mixadior/bfc"

)

//go:embed resources/out_data.yml

//go:embed resources/out_elements_filters.yml
var elementsYaml []byte

//go:embed resources/out_data_order_tree.yml
var orderTreeYaml []byte

// NewComposer unmarshals the embedded YAMLs and returns the composer used by
// /olxwizard. It takes about a second; build it once and share it — the
// composer is read-only and safe for concurrent use.
func NewComposer() (*botform.BotFormComposer, error) {
    data := &botform.BotFormDataNode{}
    if err := yaml.Unmarshal(dataYaml, data); err != nil {
        return nil, fmt.Errorf("olxform: data: %w", err)
    }

    elements := map[string]*botform.BotFormElementNode{}
    if err := yaml.Unmarshal(elementsYaml, &elements); err != nil {
        return nil, fmt.Errorf("olxform: elements: %w", err)
    }

    cityOrder := &botform.BotFormDataNode{}
    if err := yaml.Unmarshal(orderTreeYaml, cityOrder); err != nil {
        return nil, fmt.Errorf("olxform: order tree: %w", err)
    }

    elements["region"] = &botform.BotFormElementNode{
        Renderer: botform.BotChoiceKeyboardControl{
            Title:         "Область",
            ButtonsPerRow: 2,
        },
        DataPath: []string{"region"},
    }
    elements["city"] = &botform.BotFormElementNode{
        Renderer: botform.BotChoiceKeyboardControl{
            Type:          "BotMultiChoiceKeyboardControl",
            Title:         "Місто",
            ButtonsPerRow: 2,
        },
        DataPath: []string{"region", "city"},
    }
    elements["district"] = &botform.BotFormElementNode{
        Renderer: botform.BotChoiceKeyboardControl{
            Title:         "Район міста",
            ButtonsPerRow: 2,
        },
        DataPath: []string{"region", "city", "district"},
    }

    currency, ok := elements["currency"]
    if !ok {
        return nil, errors.New("olxform: elements: currency element is missing")
    }
    currency.Required = true

    return &botform.BotFormComposer{
        OrderTree: &botform.BotFormDataNode{Children: map[string]*botform.BotFormDataNode{
            "*": {
                Name: "region",
                Children: map[string]*botform.BotFormDataNode{
                    "*": cityOrder,
                }},
        }, Name: "root"},
        Data:     data,
        Elements: elements,
    }, nil
}
```

Create `search_olxua/olxform/walk.go`:

```go
package olxform

import (
    "fmt"

    botform "github.com/mixadior/bfc"
)

const maxWalkSteps = 100

// Walk returns the element names the order tree visits for values, in wizard
// order, starting after "root". Elements without a value are walked through
// their "*" branch, so the result lists every element a user would be asked
// about for the given category and location (search_name included).
func Walk(bfc *botform.BotFormComposer, values map[string]string) ([]string, error) {
    state := botform.NewState(values, botform.BfcKey{"root"})
    key := botform.BfcKey{"root"}
    seq := []string{}
    for len(seq) < maxWalkSteps {
        next, ok := bfc.GetNext(state, key)
        if !ok || next == "" {
            return seq, nil
        }
        key = append(key, next)
        seq = append(seq, next)
    }
    return nil, fmt.Errorf("olxform: order tree walk exceeded %d steps", maxWalkSteps)
}
```

```go
package olxjev

import (
    "regexp"
    "strconv"
    "strings"
)

// NumberMention is one number found in the user's text.
type NumberMention struct {
    Value float64 // normalized value: "10к" -> 10000
    Raw   string  // the mention with up to two words of context on each side
    Start int     // byte offset of the mention in the normalized text

    end        int     // byte offset right after the mention (incl. multiplier word)
    multiplier float64 // 1, 1e3 or 1e6
}

// Name is the option name used for this number in Jev questions.
func (m NumberMention) Name() string {
    return strconv.FormatFloat(m.Value, 'f', -1, 64)
}

var (
    // a number ("10", "10 000", "1,5") optionally followed by one word ("к", "тис", "м")
    numberRe = regexp.MustCompile(`(\d{1,3}(?:[ \x{00A0}]\d{3})+|\d+(?:[.,]\d+)?)(?:[ \x{00A0}]?(\pL+))?\.?`)
    phoneRe  = regexp.MustCompile(`\+?(?:38)?0\d{2}[ \-]?\d{3}[ \-]?\d{2}[ \-]?\d{2}`)
    squareRe = regexp.MustCompile(`(?i)(кв\.?\s?м|м2|m2)`)
)

var multipliers = map[string]float64{
    "к": 1e3, "k": 1e3, "тис": 1e3, "тисяч": 1e3, "тисячі": 1e3, "тисяча": 1e3,
    "тыс": 1e3, "тысяч": 1e3, "тысячи": 1e3, "тысяча": 1e3,
    "млн": 1e6, "мільйон": 1e6, "мільйона": 1e6, "мільйонів": 1e6,
    "миллион": 1e6, "миллиона": 1e6, "миллионов": 1e6,
}

var yearWords = map[string]bool{
    "р": true, "рік": true, "року": true, "г": true, "год": true, "года": true, "году": true, "рр": true,
}

var rangeGlue = map[string]bool{"-": true, "–": true, "—": true, "до": true, "по": true}

// ExtractNumbers returns every number mentioned in text, normalized, in order
// of appearance and de-duplicated by value. Phone numbers and years
// ("2015 року") are skipped; "від 8 до 12 тис" yields 8000 and 12000.
func ExtractNumbers(text string) []NumberMention {
    text = squareRe.ReplaceAllString(text, "м²")
    text = phoneRe.ReplaceAllStringFunc(text, func(s string) string {
        return strings.Repeat(" ", len(s))
    })

    mentions := []NumberMention{}
    for _, loc := range numberRe.FindAllStringSubmatchIndex(text, -1) {
        digits := strings.NewReplacer(" ", "", " ", "", ",", ".").Replace(text[loc[2]:loc[3]])
        value, err := strconv.ParseFloat(digits, 64)
        if err != nil {
            continue
        }
        m := NumberMention{Value: value, Start: loc[0], end: loc[1], multiplier: 1}
        if loc[4] >= 0 {
            word := strings.ToLower(text[loc[4]:loc[5]])
            if yearWords[word] && value >= 1950 && value <= 2035 {
                continue
            }
            if mult, ok := multipliers[word]; ok && !(isRoomsShorthand(word, text[loc[1]:])) {
                m.multiplier = mult
                m.Value = value * mult
            } else {
                // the word is not part of the number; keep it only as context
                m.end = loc[3]
            }
        }
        mentions = append(mentions, m)
    }

    // "від 8 до 12 тис", "8-12к": the first number inherits the multiplier
    for i := 0; i+1 < len(mentions); i++ {
        cur, next := &mentions[i], mentions[i+1]
        glue := strings.ToLower(strings.TrimSpace(text[cur.end:next.Start]))
        if cur.multiplier == 1 && next.multiplier > 1 && rangeGlue[glue] && cur.Value < 1000 {
            cur.multiplier = next.multiplier
            cur.Value *= next.multiplier
        }
    }

    result := []NumberMention{}
    seen := map[string]int{}
    for _, m := range mentions {
        m.Raw = contextAround(text, m.Start, m.end, 2)
        if idx, ok := seen[m.Name()]; ok {
            result[idx].Raw += " / " + m.Raw
            continue
        }
        seen[m.Name()] = len(result)
        result = append(result, m)
    }
    return result
}

// isRoomsShorthand reports whether "2к" means "2-room" ("2к квартира").
func isRoomsShorthand(word, rest string) bool {
    if word != "к" && word != "k" {
        return false
    }
    next := strings.ToLower(strings.TrimLeft(rest, " . "))
    return strings.HasPrefix(next, "кв") || strings.HasPrefix(next, "кім") || strings.HasPrefix(next, "ком")
}

// contextAround returns text[start:end] widened by up to n words on each side.
func contextAround(text string, start, end, n int) string {
    left := start
    for w := 0; w < n; w++ {
        for left > 0 && text[left-1] == ' ' {
            left--
        }
        for left > 0 && text[left-1] != ' ' {
            left--
        }
    }
    right := end
    for w := 0; w < n; w++ {
        for right < len(text) && text[right] == ' ' {
            right++
        }
        for right < len(text) && text[right] != ' ' {
            right++
        }
    }
    return strings.TrimSpace(text[left:right])
}
```

```go
package olxjev

import (
    "errors"
    "sort"
    "strings"

    botform "github.com/mixadior/bfc"
)

// Leaf is one selectable category: a leaf of the category tree.
type Leaf struct {
    Key   string   // leaf key, e.g. "category_1760"
    Label string   // "Нерухомість › Квартири › Довгострокова оренда квартир"
    Chain []string // keys from "category_1" down to Key
}

// Values returns the bfc values selecting this leaf, in the shape
// OlxBuildUrl walks: category_1=category_1757, category_1757=category_1760.
func (l Leaf) Values() map[string]string {
    values := map[string]string{}
    for i := 0; i+1 < len(l.Chain); i++ {
        values[l.Chain[i]] = l.Chain[i+1]
    }
    return values
}

// Region is one top-level location option.
type Region struct {
    ID    string
    Label string
}

// Catalog holds the closed option lists asked in stage 1.
type Catalog struct {
    Leaves  []Leaf   // sorted by Label
    Regions []Region // sorted by Label

    leafByKey   map[string]Leaf
    regionLabel map[string]string
}

// NewCatalog flattens the category tree and region list of the bfc data.
func NewCatalog(data *botform.BotFormDataNode) (*Catalog, error) {
    root, ok := data.Children["category_1"]
    if !ok {
        return nil, errors.New("olxjev: data has no category_1")
    }
    regions, ok := data.Children["region"]
    if !ok {
        return nil, errors.New("olxjev: data has no region")
    }

    c := &Catalog{leafByKey: map[string]Leaf{}, regionLabel: map[string]string{}}
    var walk func(node *botform.BotFormDataNode, chain, labels []string)
    walk = func(node *botform.BotFormDataNode, chain, labels []string) {
        if len(node.Children) == 0 {
            leaf := Leaf{
                Key:   chain[len(chain)-1],
                Label: strings.Join(labels, " › "),
                Chain: chain,
            }
            c.Leaves = append(c.Leaves, leaf)
            c.leafByKey[leaf.Key] = leaf
            return
        }
        for key, child := range node.Children {
            walk(child, append(append([]string{}, chain...), key), append(append([]string{}, labels...), child.Value))
        }
    }
    walk(root, []string{"category_1"}, []string{root.Value})
    sort.Slice(c.Leaves, func(i, j int) bool { return c.Leaves[i].Label < c.Leaves[j].Label })

    for id, region := range regions.Children {
        c.Regions = append(c.Regions, Region{ID: id, Label: region.Value})
        c.regionLabel[id] = region.Value
    }
    sort.Slice(c.Regions, func(i, j int) bool { return c.Regions[i].Label < c.Regions[j].Label })
    return c, nil
}

// Leaf returns the leaf with the given key.
func (c *Catalog) Leaf(key string) (Leaf, bool) {
    leaf, ok := c.leafByKey[key]
    return leaf, ok
}

// RegionLabel returns the region's label, or "" for an unknown id.
func (c *Catalog) RegionLabel(id string) string {
    return c.regionLabel[id]
}

// LeafOf follows the category chain in values the way OlxBuildUrl does and
// returns the final category key, or "" when no category is set.
func (c *Catalog) LeafOf(values map[string]string) string {
    key := values["category_1"]
    for i := 0; i < 20 && key != ""; i++ {
        next, ok := values[key]
        if !ok {
            return key
        }
        key = next
    }
    return key
}
```

```go
package olxjev

import (
    "errors"
    "sort"
    "strings"
    "unicode"

    botform "github.com/mixadior/bfc"
)

// CityCandidate is one shortlisted city for the stage-1 city question.
type CityCandidate struct {
    RegionID string
    CityID   string
    Label    string // "Харків, Харківська область"
    Distance int    // summed edit distance of the matched words
}

// Gazetteer shortlists cities mentioned in free text (any spelling variant,
// any grammatical case) so Jev only chooses among a handful of candidates.
type Gazetteer struct {
    cities []gazCity
}

type gazCity struct {
    regionID string
    cityID   string
    label    string
    words    [][]rune
    runeLen  int
    big      bool // has districts: the 14 biggest cities
}

type scoredCity struct {
    city     *gazCity
    distance int
}

// foldReplacer maps spelling variants onto one alphabet so
// «Харкові» and «Харькове» both fold to «харков…».
var foldReplacer = strings.NewReplacer(
    "ё", "е", "і", "и", "ї", "и", "ы", "и", "є", "е", "э", "е", "ґ", "г",
    "ь", "", "ъ", "", "'", "", "ʼ", "", "’", "", "`", "",
)

// stopWords are frequent query words that would otherwise match village names.
var stopWords = map[string]bool{}

func init() {
    for _, w := range strings.Fields(`хочу шукаю зняти зніму купити куплю продам оренда оренду орендувати
        квартиру квартира квартири будинок будинку дом кімнату кімната комнату снять сниму купить
        центр центрі центре район районі області область гривень грн доларів долларов без комісії
        тварин котом собакою поверх поверсі этаж метрів метров подобово посуточно довгострокова
        новобудова недорого терміново`) {
        for _, f := range foldWords(w) {
            stopWords[f] = true
        }
    }
}

func foldWords(s string) []string {
    s = foldReplacer.Replace(strings.ToLower(s))
    return strings.FieldsFunc(s, func(r rune) bool { return !unicode.IsLetter(r) && !unicode.IsDigit(r) })
}

// NewGazetteer indexes every city under data.Children["region"].
func NewGazetteer(data *botform.BotFormDataNode) (*Gazetteer, error) {
    regions, ok := data.Children["region"]
    if !ok {
        return nil, errors.New("olxjev: data has no region")
    }
    g := &Gazetteer{}
    for regionID, region := range regions.Children {
        for cityID, city := range region.Children {
            c := gazCity{
                regionID: regionID,
                cityID:   cityID,
                label:    city.Value + ", " + region.Value,
                big:      len(city.Children) > 0,
            }
            for _, w := range foldWords(city.Value) {
                c.words = append(c.words, []rune(w))
                c.runeLen += len([]rune(w))
            }
            if len(c.words) > 0 {
                g.cities = append(g.cities, c)
            }
        }
    }
    return g, nil
}

// Shortlist returns up to n cities whose names appear in text, best first:
// cities with districts, then lower edit distance relative to name length,
// then longer names.
func (g *Gazetteer) Shortlist(text string, n int) []CityCandidate {
    tokens := [][]rune{}
    for _, w := range foldWords(text) {
        if len([]rune(w)) >= 3 && !stopWords[w] {
            tokens = append(tokens, []rune(w))
        }
    }

    scored := []scoredCity{}
    for i := range g.cities {
        if d, ok := matchCity(&g.cities[i], tokens); ok {
            scored = append(scored, scoredCity{city: &g.cities[i], distance: d})
        }
    }
    sort.Slice(scored, func(i, j int) bool {
        a, b := scored[i], scored[j]
        if a.city.big != b.city.big {
            return a.city.big
        }
        ra := float64(a.distance) / float64(a.city.runeLen)
        rb := float64(b.distance) / float64(b.city.runeLen)
        if ra != rb {
            return ra < rb
        }
        if a.city.runeLen != b.city.runeLen {
            return a.city.runeLen > b.city.runeLen
        }
        return a.city.cityID < b.city.cityID
    })

    result := []CityCandidate{}
    for i := 0; i < len(scored) && i < n; i++ {
        c := scored[i].city
        result = append(result, CityCandidate{RegionID: c.regionID, CityID: c.cityID, Label: c.label, Distance: scored[i].distance})
    }
    return result
}

// matchCity finds the best run of consecutive tokens matching every word of
// the city name; it returns the summed distance of that run.
func matchCity(c *gazCity, tokens [][]rune) (int, bool) {
    best, found := 0, false
    for i := 0; i+len(c.words) <= len(tokens); i++ {
        sum, ok := 0, true
        for j, word := range c.words {
            d := wordDistance(word, tokens[i+j])
            if d > allowedDistance(len(word)) {
                ok = false
                break
            }
            sum += d
        }
        if ok && (!found || sum < best) {
            best, found = sum, true
        }
    }
    return best, found
}

// allowedDistance is the edit budget for a name word of n runes.
func allowedDistance(n int) int {
    switch {
    case n <= 3:
        return 0
    case n <= 5:
        return 1
    case n <= 7:
        return 2
    }
    return 3
}

// wordDistance compares a name word with prefixes of the token around the
// word's length, so inflected endings («Харкові», «Львовом») are tolerated.
func wordDistance(word, token []rune) int {
    best := len(word) + len(token)
    for k := len(word) - 1; k <= len(word)+2; k++ {
        if k < 1 || k > len(token) {
            continue
        }
        if d := levenshtein(word, token[:k]); d < best {
            best = d
        }
    }
    return best
}

func levenshtein(a, b []rune) int {
    prev := make([]int, len(b)+1)
    cur := make([]int, len(b)+1)
    for j := range prev {
        prev[j] = j
    }
    for i := 1; i <= len(a); i++ {
        cur[0] = i
        for j := 1; j <= len(b); j++ {
            cost := 1
            if a[i-1] == b[j-1] {
                cost = 0
            }
            cur[j] = min(prev[j]+1, cur[j-1]+1, prev[j-1]+cost)
        }
        prev, cur = cur, prev
    }
    return prev[len(b)]
}
```

```go
package olxjev

import (
    "fmt"
    "sort"
    "strings"

    "github.com/mattn/go-jev"
    botform "github.com/mixadior/bfc"

    "feodosian.com/olxsearch/search_olxua/olxform"
)

// NoneOption is the option name meaning "not mentioned in the query".
const NoneOption = "none"

// Stage-1 question keys.
const (
    QuestionCategory = "category"
    QuestionCity     = "city"
    QuestionRegion   = "region"
)

const noneDesc = "не вказано в запиті"

type elementKind int

const (
    kindChoice elementKind = iota // one "choice" over the element's data options
    kindMulti                     // one "noul" per data option
    kindNumber                    // one "choice" over numbers extracted from the query
)

// pendingElement is a stage-2 element still to be resolved.
type pendingElement struct {
    Key       string
    Title     string
    Kind      elementKind
    Options   map[string]string // option key -> label; empty for kindNumber
    Separator string            // kindMulti value separator
}

// stage1Questions builds the category, city and region questions. The city
// question is omitted when the shortlist is empty.
func stage1Questions(catalog *Catalog, cities []CityCandidate) map[string]jev.Question {
    categories := jev.Options{}
    for _, leaf := range catalog.Leaves {
        categories = append(categories, jev.Option{Name: leaf.Key, Desc: leaf.Label})
    }
    categories = append(categories, jev.Option{Name: NoneOption, Desc: noneDesc})

    regions := jev.Options{}
    for _, r := range catalog.Regions {
        regions = append(regions, jev.Option{Name: r.ID, Desc: r.Label})
    }
    regions = append(regions, jev.Option{Name: NoneOption, Desc: noneDesc})

    questions := map[string]jev.Question{
        QuestionCategory: {
            Type:         "choice",
            Instructions: "Яку категорію нерухомості на OLX шукає користувач (купівля, довгострокова чи подобова оренда; квартира, будинок, кімната тощо)?",
            Criteria:     categories,
        },
        QuestionRegion: {
            Type:         "choice",
            Instructions: "У якій області України користувач шукає нерухомість? Якщо область не випливає із запиту, обери \"none\".",
            Criteria:     regions,
        },
    }
    if len(cities) > 0 {
        options := jev.Options{}
        for _, c := range cities {
            options = append(options, jev.Option{Name: c.CityID, Desc: c.Label})
        }
        options = append(options, jev.Option{Name: NoneOption, Desc: noneDesc})
        questions[QuestionCity] = jev.Question{
            Type:         "choice",
            Instructions: "У якому населеному пункті користувач шукає нерухомість? Якщо жоден варіант не згаданий у запиті, обери \"none\".",
            Criteria:     options,
        }
    }
    return questions
}

// skipInStage2 lists elements stage 2 never asks about: location is settled
// in stage 1 and the search name is not part of the URL.
var skipInStage2 = map[string]bool{"region": true, "city": true, "search_name": true}

// applicableElements walks the order tree with the stage-1 values and returns
// the elements stage 2 should resolve, in wizard order.
func applicableElements(bfc *botform.BotFormComposer, values map[string]string) ([]pendingElement, error) {
    seq, err := olxform.Walk(bfc, values)
    if err != nil {
        return nil, err
    }
    state := botform.NewState(values, botform.BfcKey{"root"})

    elements := []pendingElement{}
    for _, key := range seq {
        if _, set := values[key]; set || skipInStage2[key] || strings.HasPrefix(key, "category_") {
            continue
        }
        el, ok := bfc.GetElement(key)
        if !ok {
            continue
        }
        switch r := el.Renderer.(type) {
        case botform.BotTextKeyboardControl:
            if strings.HasPrefix(key, "filter_float_") {
                elements = append(elements, pendingElement{Key: key, Title: r.Title, Kind: kindNumber})
            }
        case botform.BotMultiChoiceKeyboardControl:
            options, err := bfc.GetChoicesByPath(state, el.DataPath, true)
            if err != nil || len(options) == 0 {
                continue
            }
            separator := r.ValuesSeparator
            if separator == "" {
                separator = ";"
            }
            elements = append(elements, pendingElement{Key: key, Title: r.Title, Kind: kindMulti, Options: options, Separator: separator})
        case botform.BotChoiceKeyboardControl:
            options, err := bfc.GetChoicesByPath(state, el.DataPath, true)
            if err != nil {
                continue
            }
            if strings.HasPrefix(key, "filter_bool_") {
                // "0" means "all ads" (same as not asking) and OlxBuildUrl would
                // turn any non-empty bool value into an active filter.
                options = map[string]string{"1": options["1"]}
            }
            if len(options) == 0 {
                continue
            }
            elements = append(elements, pendingElement{Key: key, Title: r.Title, Kind: kindChoice, Options: options})
        }
    }
    return elements, nil
}

// stage2Questions builds one question per choice/number element and one noul
// per option of every multi-choice element. Number questions are only asked
// when the query contains numbers.
func stage2Questions(elements []pendingElement, numbers []NumberMention) map[string]jev.Question {
    questions := map[string]jev.Question{}
    for _, el := range elements {
        switch el.Kind {
        case kindChoice:
            options := jev.Options{}
            for _, key := range sortedKeys(el.Options) {
                options = append(options, jev.Option{Name: key, Desc: el.Options[key]})
            }
            options = append(options, jev.Option{Name: NoneOption, Desc: noneDesc})
            questions[el.Key] = jev.Question{
                Type:         "choice",
                Instructions: fmt.Sprintf("%s: який варіант відповідає запиту користувача? Якщо в запиті про це не сказано, обери \"none\".", el.Title),
                Criteria:     options,
            }
        case kindMulti:
            for _, key := range sortedKeys(el.Options) {
                questions[multiKey(el.Key, key)] = jev.Question{
                    Type:         "noul",
                    Instructions: fmt.Sprintf("%s: чи підходить користувачу варіант «%s»? Так — лише якщо запит прямо або однозначно на це вказує.", el.Title, el.Options[key]),
                }
            }
        case kindNumber:
            if len(numbers) == 0 {
                continue
            }
            options := jev.Options{}
            for _, m := range numbers {
                options = append(options, jev.Option{Name: m.Name(), Desc: "«" + m.Raw + "»"})
            }
            options = append(options, jev.Option{Name: NoneOption, Desc: noneDesc})
            questions[el.Key] = jev.Question{
                Type:         "choice",
                Instructions: fmt.Sprintf("Поле «%s» (%s): яке число із запиту користувача є значенням цього поля? Якщо жодне, обери \"none\".", el.Title, boundHint(el.Key)),
                Criteria:     options,
            }
        }
    }
    return questions
}

// multiKey is the question key for one option of a multi-choice element.
func multiKey(element, option string) string {
    return element + "#" + option
}

func boundHint(key string) string {
    switch {
    case strings.HasSuffix(key, ":from"):
        return "нижня межа, «від»"
    case strings.HasSuffix(key, ":to"):
        return "верхня межа, «до»"
    }
    return "точне значення"
}

func sortedKeys(m map[string]string) []string {
    keys := make([]string, 0, len(m))
    for k := range m {
        keys = append(keys, k)
    }
    sort.Strings(keys)
    return keys
}
```

```go
package olxjev

import (
    "context"

    "github.com/mattn/go-jev"
)

// fakeJev answers every question with "none" (choice) or 0.01 (noul) unless
// a canned answer for that call index and question key is given.
type fakeJev struct {
    answers []map[string]*jev.Answer // per call
    errs    []error                  // per call
    calls   []fakeCall
}

type fakeCall struct {
    state     any
    questions map[string]jev.Question
}

func (f *fakeJev) Evaluate(_ context.Context, state, questions any) (*jev.Response, error) {
    i := len(f.calls)
    qs := questions.(map[string]jev.Question)
    f.calls = append(f.calls, fakeCall{state: state, questions: qs})
    if i < len(f.errs) && f.errs[i] != nil {
        return nil, f.errs[i]
    }
    resp := &jev.Response{Answers: map[string]*jev.Answer{}}
    for key, q := range qs {
        if q.Type == "noul" {
            resp.Answers[key] = noul(0.01)
        } else {
            resp.Answers[key] = choice(NoneOption, 0.9)
        }
    }
    if i < len(f.answers) {
        for key, a := range f.answers[i] {
            resp.Answers[key] = a
        }
    }
    return resp, nil
}

func choice(option string, confidence float64) *jev.Answer {
    return &jev.Answer{Type: "choice", Choice: option, Confidence: confidence}
}

func noul(p float64) *jev.Answer {
    return &jev.Answer{Type: "noul", Noul: p}
}
```

```go
// Package olxjev turns a free-text real-estate request («хочу зняти однушку
// в Харкові до 10к») into the bfc values of the OLX.ua wizard, letting Jev
// make the wizard's choices. See docs/superpowers/specs/2026-10-14-olxjev-design.md.
package olxjev

import (
    "context"
    "errors"
    "fmt"
    "strconv"
    "strings"

    "github.com/mattn/go-jev"
    botform "github.com/mixadior/bfc"
    "github.com/rs/zerolog"
)

const (
    // DefaultThreshold is the minimum Jev confidence (or noul probability)
    // for an answer to be accepted.
    DefaultThreshold = 0.5
    // DefaultShortlist is how many city candidates stage 1 offers Jev.
    DefaultShortlist = 8
)

// Field sources.
const (
    SourceJev     = "jev"
    SourceDerived = "derived" // region implied by the accepted city
)

var (
    // ErrCategoryUnresolved means stage 1 could not settle the category; no
    // valid OLX URL can be built without it.
    ErrCategoryUnresolved = errors.New("olxjev: category unresolved")
    // ErrEmptyQuery is returned for a blank query.
    ErrEmptyQuery = errors.New("olxjev: empty query")
)

// Evaluator is the subset of *jev.Client the resolver needs.
type Evaluator interface {
    Evaluate(ctx context.Context, state, questions any) (*jev.Response, error)
}

// TraceFunc observes every Jev exchange; resp is nil when the call failed.
type TraceFunc func(stage string, state any, questions map[string]jev.Question, resp *jev.Response)

// FieldInfo describes one resolved field.
type FieldInfo struct {
    Value      string  `json:"value"`
    Label      string  `json:"label"`
    Confidence float64 `json:"confidence"`
    Source     string  `json:"source"`
}

// Result is the outcome of Resolve.
type Result struct {
    // Values has the bfc State.Values shape and feeds search_olxua.OlxBuildUrl.
    Values map[string]string `json:"values"`
    // Fields describes each resolved element ("category" for the leaf).
    Fields map[string]FieldInfo `json:"fields"`
    // Skipped lists applicable elements left unset, in wizard order.
    Skipped []string `json:"skipped"`
}

// Resolver resolves free-text queries. Configure the exported fields before
// the first Resolve; a Resolver is safe for concurrent use afterwards.
type Resolver struct {
    Composer  *botform.BotFormComposer
    Catalog   *Catalog
    Gazetteer *Gazetteer
    Jev       Evaluator
    Threshold float64 // 0 means DefaultThreshold
    Shortlist int     // 0 means DefaultShortlist
    Log       *zerolog.Logger
    Trace     TraceFunc
}

// NewResolver builds the catalog and gazetteer from the composer's data.
func NewResolver(composer *botform.BotFormComposer, evaluator Evaluator) (*Resolver, error) {
    catalog, err := NewCatalog(composer.Data)
    if err != nil {
        return nil, err
    }
    gazetteer, err := NewGazetteer(composer.Data)
    if err != nil {
        return nil, err
    }
    return &Resolver{Composer: composer, Catalog: catalog, Gazetteer: gazetteer, Jev: evaluator}, nil
}

// Resolve runs the two Jev stages for text. On a stage-2 failure it returns
// the partial result (category and location) together with the error; on
// ErrCategoryUnresolved the result carries whatever stage 1 produced.
func (r *Resolver) Resolve(ctx context.Context, text string) (*Result, error) {
    text = strings.TrimSpace(text)
    if text == "" {
        return nil, ErrEmptyQuery
    }
    numbers := ExtractNumbers(text)
    cities := r.Gazetteer.Shortlist(text, r.shortlist())

    q1 := stage1Questions(r.Catalog, cities)
    resp1, err := r.evaluate(ctx, "stage1", text, q1)
    if err != nil {
        return nil, fmt.Errorf("stage1: %w", err)
    }

    res := &Result{Values: map[string]string{}, Fields: map[string]FieldInfo{}}
    resolved := map[string]string{}

    leafKey, conf, ok := r.acceptChoice(resp1, QuestionCategory, q1)
    if !ok {
        res.Skipped = append(res.Skipped, QuestionCategory)
        return res, ErrCategoryUnresolved
    }
    leaf, _ := r.Catalog.Leaf(leafKey)
    for k, v := range leaf.Values() {
        res.Values[k] = v
    }
    res.Fields[QuestionCategory] = FieldInfo{Value: leaf.Key, Label: leaf.Label, Confidence: conf, Source: SourceJev}
    resolved["Категорія"] = leaf.Label

    if cityID, conf, ok := r.acceptChoice(resp1, QuestionCity, q1); ok {
        city := candidateByID(cities, cityID)
        res.Values["region"] = city.RegionID
        res.Values["city"] = city.CityID
        res.Fields["city"] = FieldInfo{Value: city.CityID, Label: city.Label, Confidence: conf, Source: SourceJev}
        res.Fields["region"] = FieldInfo{Value: city.RegionID, Label: r.Catalog.RegionLabel(city.RegionID), Confidence: conf, Source: SourceDerived}
        resolved["Місто"] = city.Label
    } else if regionID, conf, ok := r.acceptChoice(resp1, QuestionRegion, q1); ok {
        label := r.Catalog.RegionLabel(regionID)
        res.Values["region"] = regionID
        res.Fields["region"] = FieldInfo{Value: regionID, Label: label, Confidence: conf, Source: SourceJev}
        res.Skipped = append(res.Skipped, "city")
        resolved["Область"] = label
    } else {
        res.Skipped = append(res.Skipped, "region", "city")
    }

    elements, err := applicableElements(r.Composer, res.Values)
    if err != nil {
        return res, fmt.Errorf("stage2: %w", err)
    }
    q2 := stage2Questions(elements, numbers)
    if len(q2) == 0 {
        return res, nil
    }
    state2 := map[string]any{"query": text, "resolved": resolved}
    resp2, err := r.evaluate(ctx, "stage2", state2, q2)
    if err != nil {
        return res, fmt.Errorf("stage2: %w", err)
    }
    r.applyStage2(res, elements, numbers, q2, resp2)
    return res, nil
}

func (r *Resolver) evaluate(ctx context.Context, stage string, state any, questions map[string]jev.Question) (*jev.Response, error) {
    resp, err := r.Jev.Evaluate(ctx, state, questions)
    if r.Trace != nil {
        r.Trace(stage, state, questions, resp)
    }
    if err != nil {
        return nil, err
    }
    if resp == nil || resp.Answers == nil {
        return nil, errors.New("jev returned no answers")
    }
    return resp, nil
}

// acceptChoice validates a "choice" answer: it must name an option that was
// sent, must not be NoneOption and must reach the threshold.
func (r *Resolver) acceptChoice(resp *jev.Response, key string, questions map[string]jev.Question) (string, float64, bool) {
    q, asked := questions[key]
    if !asked {
        return "", 0, false
    }
    a := resp.Answers[key]
    if a == nil {
        return "", 0, false
    }
    options, _ := q.Criteria.(jev.Options)
    if !hasOption(options, a.Choice) {
        r.log().Warn().Str("question", key).Str("choice", a.Choice).Msg("olxjev: jev chose an option that was not offered")
        return "", 0, false
    }
    conf := answerConfidence(a)
    if a.Choice == NoneOption || conf < r.threshold() {
        return "", conf, false
    }
    return a.Choice, conf, true
}

type numberClaim struct {
    key  string
    name string
    conf float64
}

func (r *Resolver) applyStage2(res *Result, elements []pendingElement, numbers []NumberMention, questions map[string]jev.Question, resp *jev.Response) {
    claims := []numberClaim{}
    for _, el := range elements {
        switch el.Kind {
        case kindChoice:
            value, conf, ok := r.acceptChoice(resp, el.Key, questions)
            if !ok {
                res.Skipped = append(res.Skipped, el.Key)
                continue
            }
            res.Values[el.Key] = value
            res.Fields[el.Key] = FieldInfo{Value: value, Label: el.Options[value], Confidence: conf, Source: SourceJev}
        case kindMulti:
            accepted, labels, minConf := []string{}, []string{}, 1.0
            for _, option := range sortedKeys(el.Options) {
                a := resp.Answers[multiKey(el.Key, option)]
                if a == nil || a.Noul < r.threshold() {
                    continue
                }
                accepted = append(accepted, option)
                labels = append(labels, el.Options[option])
                minConf = min(minConf, a.Noul)
            }
            if len(accepted) == 0 {
                res.Skipped = append(res.Skipped, el.Key)
                continue
            }
            value := strings.Join(accepted, el.Separator)
            res.Values[el.Key] = value
            res.Fields[el.Key] = FieldInfo{Value: value, Label: strings.Join(labels, ", "), Confidence: minConf, Source: SourceJev}
        case kindNumber:
            name, conf, ok := r.acceptChoice(resp, el.Key, questions)
            if !ok {
                res.Skipped = append(res.Skipped, el.Key)
                continue
            }
            claims = append(claims, numberClaim{key: el.Key, name: name, conf: conf})
        }
    }

    kept, dropped := settleNumberClaims(claims)
    raw := map[string]string{}
    for _, m := range numbers {
        raw[m.Name()] = m.Raw
    }
    for _, c := range kept {
        res.Values[c.key] = c.name
        res.Fields[c.key] = FieldInfo{Value: c.name, Label: raw[c.name], Confidence: c.conf, Source: SourceJev}
    }
    for _, c := range dropped {
        res.Skipped = append(res.Skipped, c.key)
    }
}

// settleNumberClaims enforces two rules, keeping claims in input order:
//  1. one number belongs to at most one field family (price, area, floor, …);
//     the family holding the most confident claim on it wins;
//  2. within a family, from must not exceed to; the less confident side is dropped.
func settleNumberClaims(claims []numberClaim) (kept, dropped []numberClaim) {
    winner := map[string]numberClaim{} // number -> most confident claim
    for _, c := range claims {
        if w, ok := winner[c.name]; !ok || c.conf > w.conf {
            winner[c.name] = c
        }
    }
    stage := []numberClaim{}
    for _, c := range claims {
        if family(c.key) == family(winner[c.name].key) {
            stage = append(stage, c)
        } else {
            dropped = append(dropped, c)
        }
    }

    bounds := map[string]map[string]numberClaim{} // family -> "from"/"to" -> claim
    for _, c := range stage {
        f := family(c.key)
        if bounds[f] == nil {
            bounds[f] = map[string]numberClaim{}
        }
        bounds[f][bound(c.key)] = c
    }
    for _, c := range stage {
        b := bounds[family(c.key)]
        from, hasFrom := b["from"]
        to, hasTo := b["to"]
        if hasFrom && hasTo && parseNumber(from.name) > parseNumber(to.name) {
            loser := from
            if from.conf > to.conf {
                loser = to
            }
            if c.key == loser.key {
                dropped = append(dropped, c)
                continue
            }
        }
        kept = append(kept, c)
    }
    return kept, dropped
}

// family strips the :from / :to suffix: filter_float_price:to -> filter_float_price.
func family(key string) string {
    if i := strings.LastIndex(key, ":"); i >= 0 {
        return key[:i]
    }
    return key
}

func bound(key string) string {
    if i := strings.LastIndex(key, ":"); i >= 0 {
        return key[i+1:]
    }
    return ""
}

func parseNumber(s string) float64 {
    v, _ := strconv.ParseFloat(s, 64)
    return v
}

func hasOption(options jev.Options, name string) bool {
    for _, o := range options {
        if o.Name == name {
            return true
        }
    }
    return false
}

// answerConfidence prefers the answer's Confidence and falls back to the
// probability of the chosen option.
func answerConfidence(a *jev.Answer) float64 {
    if a.Confidence > 0 {
        return a.Confidence
    }
    return a.Probabilities[a.Choice]
}

func candidateByID(cities []CityCandidate, id string) CityCandidate {
    for _, c := range cities {
        if c.CityID == id {
            return c
        }
    }
    return CityCandidate{}
}

func (r *Resolver) threshold() float64 {
    if r.Threshold > 0 {
        return r.Threshold
    }
    return DefaultThreshold
}

func (r *Resolver) shortlist() int {
    if r.Shortlist > 0 {
        return r.Shortlist
    }
    return DefaultShortlist
}

var nopLogger = zerolog.Nop()

func (r *Resolver) log() *zerolog.Logger {
    if r.Log == nil {
        return &nopLogger
    }
    return r.Log
}
```

```go
// Command olxjev resolves free-text real-estate queries into OLX.ua search
// URLs using Jev. Usage:
//
//     TYPESAFE_API_KEY=... olxjev -q "хочу зняти однушку в Харкові до 10к"
//     olxjev -json < queries.txt
package main

import (
    "bufio"
    "context"
    "encoding/json"
    "errors"
    "fmt"
    "flag"
    "io"
    "os"
    "sort"
    "strings"
    "time"

    "github.com/mattn/go-jev"

    "feodosian.com/olxsearch/request"
    "feodosian.com/olxsearch/search_olxua"

    "feodosian.com/olxsearch/search_olxua/olxform"
    "feodosian.com/olxsearch/olxjev"
)

func main() {
    os.Exit(run(os.Args[1:], os.Stdin, os.Stdout, os.Stderr, os.Getenv))
}

// output is the -json shape of one resolved query.
type output struct {
    Query  string         `json:"query"`
    Result *olxjev.Result `json:"result,omitempty"`
    URL    string         `json:"url,omitempty"`
    Error  string         `json:"error,omitempty"`
}

func run(args []string, stdin io.Reader, stdout, stderr io.Writer, getenv func(string) string) int {
    fs := flag.NewFlagSet("olxjev", flag.ContinueOnError)
    fs.SetOutput(stderr)
    query := fs.String("q", "", "query text; when empty, queries are read from stdin, one per line")
    threshold := fs.Float64("threshold", olxjev.DefaultThreshold, "minimum Jev confidence to accept an answer")
    asJSON := fs.Bool("json", false, "print results as JSON lines")
    noURL := fs.Bool("no-url", false, "do not call OLX to build the search URL")
    debug := fs.Bool("debug", false, "print the Jev state, questions and raw answers to stderr")
    endpoint := fs.String("endpoint", jev.DefaultURL, "Jev API endpoint")
    if err := fs.Parse(args); err != nil {
        return 2
    }

    apiKey := getenv("TYPESAFE_API_KEY")
    if apiKey == "" && *endpoint == jev.DefaultURL {
        fmt.Fprintln(stderr, "olxjev: TYPESAFE_API_KEY is not set")
        return 2
    }

    composer, err := olxform.NewComposer()
    if err != nil {
        fmt.Fprintln(stderr, "olxjev:", err)
        return 1
    }
    client := jev.NewClient(
        jev.WithAPIKey(apiKey),
        jev.WithURL(*endpoint),
        jev.WithTimeout(30*time.Second),
        jev.WithMaxRetries(3),
    )
    resolver, err := olxjev.NewResolver(composer, client)
    if err != nil {
        fmt.Fprintln(stderr, "olxjev:", err)
        return 1
    }
    resolver.Threshold = *threshold
    if *debug {
        resolver.Trace = func(stage string, state any, questions map[string]jev.Question, resp *jev.Response) {
            dump, _ := json.MarshalIndent(map[string]any{"stage": stage, "state": state, "questions": questions}, "", "  ")
            fmt.Fprintln(stderr, string(dump))
            if resp != nil {
                fmt.Fprintln(stderr, string(resp.Raw))
            }
        }
    }

    queries := []string{*query}
    if *query == "" {
        queries = readLines(stdin)
    }

    var rq request.Request
    if !*noURL {
        rq = request.NewLocalRequest()
    }

    exit := 0
    ctx := context.Background()
    for _, q := range queries {
        out := resolveOne(ctx, resolver, q, rq)
        if out.Error != "" {
            exit = 1
        }
        if *asJSON {
            line, _ := json.Marshal(out)
            fmt.Fprintln(stdout, string(line))
        } else {
            printText(stdout, out)
        }
    }
    return exit
}

func resolveOne(ctx context.Context, resolver *olxjev.Resolver, query string, rq request.Request) output {
    out := output{Query: query}
    res, err := resolver.Resolve(ctx, query)
    out.Result = res
    if err != nil {
        out.Error = err.Error()
    }
    if rq == nil || res == nil || errors.Is(err, olxjev.ErrCategoryUnresolved) {
        return out
    }
    url, urlErr := search_olxua.OlxBuildUrl(ctx, res.Values, rq)
    if urlErr != nil {
        out.Error = strings.TrimPrefix(out.Error+"; ", "; ") + "url: " + urlErr.Error()
        return out
    }
    out.URL = url
    return out
}

func printText(w io.Writer, out output) {
    fmt.Fprintf(w, "query: %s\n", out.Query)
    if out.Result != nil {
        keys := make([]string, 0, len(out.Result.Fields))
        for k := range out.Result.Fields {
            keys = append(keys, k)
        }
        sort.Strings(keys)
        for _, k := range keys {
            f := out.Result.Fields[k]
            fmt.Fprintf(w, "  %s = %s  [%s, %.2f]\n", k, f.Value, f.Label, f.Confidence)
        }
        if len(out.Result.Skipped) > 0 {
            fmt.Fprintf(w, "  skipped: %s\n", strings.Join(out.Result.Skipped, ", "))
        }
    }
    if out.URL != "" {
        fmt.Fprintf(w, "  url: %s\n", out.URL)
    }
    if out.Error != "" {
        fmt.Fprintf(w, "  error: %s\n", out.Error)
    }
}

func readLines(r io.Reader) []string {
    lines := []string{}
    scanner := bufio.NewScanner(r)
    for scanner.Scan() {
        if line := strings.TrimSpace(scanner.Text()); line != "" {
            lines = append(lines, line)
        }
    }
    return lines
}
```

```go
package olxjev

import (
    "context"
    "fmt"
    "os"
    "sort"
    "strings"
    "testing"
    "time"

    "github.com/mattn/go-jev"
    botform "github.com/mixadior/bfc"
    "gopkg.in/yaml.v2"
)

type goldenCase struct {
    Q      string            `yaml:"q"`
    Expect map[string]string `yaml:"expect"`
}

// Accuracy floors enforced by TestGolden; other fields are reported only.
var goldenFloors = map[string]float64{"category": 0.9, "city": 0.9}

func loadGolden(t *testing.T) []goldenCase {
    t.Helper()
    raw, err := os.ReadFile("testdata/golden.yaml")
    if err != nil {
        t.Fatalf("read golden.yaml: %v", err)
    }
    cases := []goldenCase{}
    if err := yaml.Unmarshal(raw, &cases); err != nil {
        t.Fatalf("parse golden.yaml: %v", err)
    }
    return cases
}

// TestGoldenCorpusIsValid runs offline: every expected category exists and
// every expected field applies to that category, so corpus typos fail fast.
func TestGoldenCorpusIsValid(t *testing.T) {
    bfc := testComposer(t)
    catalog, err := NewCatalog(bfc.Data)
    if err != nil {
        t.Fatalf("NewCatalog: %v", err)
    }
    cases := loadGolden(t)
    if len(cases) < 40 {
        t.Errorf("golden corpus has %d cases, want at least 40", len(cases))
    }
    for _, c := range cases {
        leaf, ok := catalog.Leaf(c.Expect["category"])
        if !ok {
            t.Errorf("%q: unknown category %q", c.Q, c.Expect["category"])
            continue
        }
        values := leaf.Values()
        if region, ok := c.Expect["region"]; ok {
            if catalog.RegionLabel(region) == "" {
                t.Errorf("%q: unknown region %q", c.Q, region)
            }
            values["region"] = region
        }
        if city, ok := c.Expect["city"]; ok {
            region := cityRegion(bfc.Data.Children["region"].Children, city)
            if region == "" {
                t.Errorf("%q: unknown city %q", c.Q, city)
                continue
            }
            values["region"], values["city"] = region, city
        }
        elements, err := applicableElements(bfc, values)
        if err != nil {
            t.Fatalf("%q: applicableElements: %v", c.Q, err)
        }
        applicable := map[string]pendingElement{}
        for _, el := range elements {
            applicable[el.Key] = el
        }
        for key, want := range c.Expect {
            if key == "category" || key == "region" || key == "city" {
                continue
            }
            el, ok := applicable[key]
            if !ok {
                t.Errorf("%q: %s does not apply to %s", c.Q, key, leaf.Key)
                continue
            }
            if el.Kind == kindNumber {
                continue
            }
            options := []string{want}
            if el.Kind == kindMulti {
                options = strings.Split(want, el.Separator)
            }
            for _, option := range options {
                if _, ok := el.Options[option]; !ok {
                    t.Errorf("%q: %s has no option %q", c.Q, key, option)
                }
            }
        }
    }
}

// TestGolden calls the live TypeSafe API and reports per-field accuracy.
// Run: OLXJEV_LIVE=1 TYPESAFE_API_KEY=... go test -run TestGolden -v ./olxjev/
func TestGolden(t *testing.T) {
    if os.Getenv("OLXJEV_LIVE") != "1" || os.Getenv("TYPESAFE_API_KEY") == "" {
        t.Skip("set OLXJEV_LIVE=1 and TYPESAFE_API_KEY to run the live golden eval (spends API credits)")
    }
    client := jev.NewClient(jev.WithAPIKey(os.Getenv("TYPESAFE_API_KEY")), jev.WithTimeout(30*time.Second))
    r, err := NewResolver(testComposer(t), client)
    if err != nil {
        t.Fatalf("NewResolver: %v", err)
    }

    type stat struct{ hit, total int }
    stats := map[string]*stat{}
    for _, c := range loadGolden(t) {
        res, err := r.Resolve(context.Background(), c.Q)
        values := map[string]string{}
        if res != nil {
            values = res.Values
        }
        if err != nil {
            t.Logf("%q: %v", c.Q, err)
        }
        for key, want := range c.Expect {
            got := values[key]
            if key == "category" {
                got = r.Catalog.LeafOf(values)
            }
            if stats[key] == nil {
                stats[key] = &stat{}
            }
            stats[key].total++
            if got == want {
                stats[key].hit++
            } else {
                t.Logf("MISS %q: %s = %q, want %q", c.Q, key, got, want)
            }
        }
    }

    keys := make([]string, 0, len(stats))
    for k := range stats {
        keys = append(keys, k)
    }
    sort.Strings(keys)
    report := []string{"field accuracy:"}
    for _, k := range keys {
        s := stats[k]
        report = append(report, fmt.Sprintf("  %-40s %3d/%-3d %5.1f%%", k, s.hit, s.total, 100*float64(s.hit)/float64(s.total)))
    }
    t.Log(strings.Join(report, "\n"))

    for field, floor := range goldenFloors {
        if s := stats[field]; s != nil && float64(s.hit)/float64(s.total) < floor {
            t.Errorf("%s accuracy %.1f%% is below the %.0f%% floor", field, 100*float64(s.hit)/float64(s.total), 100*floor)
        }
    }
}

func cityRegion(regions map[string]*botform.BotFormDataNode, city string) string {
    for id, region := range regions {
        if _, ok := region.Children[city]; ok {
            return id
        }
    }
    return ""
}
```
